How this page is put together

Rackspace pools and market prices are read live through the Rackspace Spot connector. Workers, the queue and Kubernetes node counts come from fleet/summary.json in the lab bucket, which the Fleet status workflow writes every 10 minutes, read through the Google Cloud CLI connector. VM pool counts come from fleet/sources.json, which the lab chat keeps; Rackspace's VM pool listing is not read here because it carries machine setup data. Regions follow the class suffix: ord Chicago, hkg Hong Kong, iad US East, iad2 US East 2, dfw Dallas, lon London, syd Sydney.
